# Менеджер 1.4 — рассылки и поиск партнёров

## Что готово

В Telegram: Главное меню → Менеджер → Кампании → Создать кампанию.
Укажи название, общий текст и группы. Принимаются @username, публичные ссылки
https://t.me/group и числовые ID групп. Дубликаты ссылок убираются; при проверке
также объединяются разные адреса одной группы. Кампания сохраняется выключенной.
Старые черновики и сохранённые контакты остаются доступны.

В карточке кампании есть Старт, Стоп, Изменить пост, Предпросмотр, Группы,
Интервалы и Журнал. Из любой формы можно отменить ввод и вернуться назад.
В менеджере не показываются кнопки СММ. Состояние экрана у совладельцев отдельное.

## Расписание

После первого нажатия «Старт» бот проверяет, что аккаунт уже состоит в каждой
указанной группе и ему разрешена отправка текста. Затем начинает рассылку.
Автоматического вступления в группы и отправки в личные аккаунты нет.
Разрешение рекламы со стороны администрации нужно проверить самому: техническое
право отправлять текст не означает разрешение размещать рекламу.

| Этап | Пример времени |
| --- | --- |
| Группа 1 | 12:00 |
| Группа 2 | 12:02 |
| Группа 3 | 12:04 |
| Группа 1 — следующий круг | 12:30 |
| Группа 2 | 12:32 |

Пауза между группами — не меньше 2 минут. В нормальных условиях круг начинается
через 30 минут от начала предыдущего. Если групп больше 15, он удлиняется:
16 групп при паузе 2 минуты требуют минимум 32 минуты. Ошибки сети, чтение
данных поиска и ограничения Telegram могут задержать отправку; ускоренной
компенсации пропущенного нет. Все времена в боте — московские.

На одном аккаунте работает одна кампания одновременно. Между кампаниями
сохраняется общая пауза. Также сохраняется период до следующей отправки
в конкретную группу: замена списка и перезапуск не обнуляют эту защиту.
Дневной предел по умолчанию — 500 отправок на аккаунт. Его можно изменить
в карточке; это ограничение программы, не разрешённая Telegram квота.

«Стоп» отменяет следующие отправки. Уже начатый запрос может завершиться:
отозвать переданное серверу сообщение задним числом эта кнопка не может.
«Остановить всё» в менеджере выключает все рассылки и отменяет поиск.
Пауза в СММ и остановка менеджера работают независимо.

## Изменение поста

В кампании нажми «Изменить пост» и пришли новый текст. Ещё не начатые отправки
используют новую версию; старые сообщения в группах не редактируются.
Журнал сохраняет номер версии и текст каждой попытки. Поддерживается общий
обычный текст до 3500 символов Telegram; форматирование, фото, альбомы,
пересылка существующего поста и редактирование уже отправленных сообщений
в эту версию не входят.

Замена групп, интервалов или дневного предела останавливает кампанию.
После проверки настроек нажми Старт. Редактирование этих параметров запрещено,
пока есть незавершённая отправка. Общий текст можно менять без остановки.

## Ошибки и перезапуск

При FloodWait/SlowModeWait сохраняется требуемая Telegram пауза; кампания
останавливается. После ожидания её запускает владелец. Скрытых повторов нет.
Если группа недоступна или отправка запрещена, журнал показывает ошибку,
кампания останавливается до исправления.

Если процесс прервался или ответ на отправку потерялся, результат неизвестен.
Бот не повторяет сообщение автоматически. В журнале открой указанную группу:
если пост уже есть, нажми «Уже в группе»; иначе — «Пропустить». Затем вручную
нажми Старт: продолжится со следующей группы. Проверку результата должен
выполнить человек. Журнал заранее сохраняет уникальный random_id запроса.

Известные завершённые отправки, очередность, интервалы и пределы переживают
перезапуск. Не устанавливай обновление параллельно с работающим процессом.
Интервалы не гарантируют отсутствие блокировки за нежелательную рекламу.

## Поиск партнёров

Менеджер → Партнёры → Фильтры:

- До трёх поисковых фраз по 3–80 знаков, например «нейросети, ai tools, технологии».
- Минимум и максимум подписчиков; 0 0 — без ограничения.
- Свой подключённый канал для рекомендаций.
- Все похожие каналы или описания с упоминанием сотрудничества/ВП.

Нажми «Найти ещё до 10». Используются поиск публичных каналов Telegram и
рекомендации похожих каналов к выбранному. Это сетевые запросы с подключённого
аккаунта, не локальная база всех каналов и не полный обход Telegram.
Платный поиск постов и Telegram Stars не используются. ИИ для этого поиска
не вызывается, его токены не тратятся.

За запуск возвращается до 10 новых каналов. При нехватке совпадений их будет
меньше; дополнительные результаты бот не выдумывает. Показаны ссылка, описание,
число подписчиков, время последнего поста, если доступны, и источник находки.
Ранее найденные и скрытые каналы не предлагаются повторно. Свои подключённые
каналы исключаются. Доступны избранное, скрытие и контакты с заметками.

Поиск проверяет ограниченную выдачу: до 3 фраз и до 20 карточек каналов.
Следующий запуск доступен не раньше чем через 2 минуты. Рекомендации зависят
от доступности метода аккаунту; число результатов может быть ограничено Telegram.
При ошибке сохранённые находки остаются в списке.

Найденные каналы НЕ добавляются в рассылку. Автоматических сообщений,
подписок и переговоров нет. Упоминание сотрудничества в описании не доказывает,
что владелец согласится на взаимную подписку или взаимный пост.

## Как подключить отправляющий аккаунт

Пока аккаунта/API нет, оставь подключение выключенным. Меню и черновики доступны,
нажатие Старт не отправляет сообщения. Авторизация ChatGPT и Bot Token здесь
не используются. Нужны Telegram API ID/hash из https://my.telegram.org/apps.

Добавь в ENV хостинга:

| Переменная | Значение |
| --- | --- |
| MANAGER_ENABLED | `1` после подготовки подключения; `0` пока выключено |
| MANAGER_API_ID | свой числовой Telegram API ID |
| MANAGER_API_HASH | свой Telegram API hash |
| SMM_DATA_DIR | оставить `/app/data/smm` |

Новые параметры хранятся в ENV, не в открытом репозитории. Старый файл
MANAGER_ACCOUNT.json.example эта версия не читает. Перед запуском пересобери
requirements.txt: добавлена зависимость Telethon>=1.45,<2.

Останови бот и в защищённом ИНТЕРАКТИВНОМ терминале запусти:

```
python main.py manager-login
```

Введи телефон, код и пароль 2FA, если требуется. Ввод скрыт. Авторизация не
отправляет рекламных сообщений. Обычная строка команд Bothost без интерактивного
ввода не подходит: команда завершится без запроса кода. Потребуется интерактивная
консоль/SSH, если они доступны на тарифе, или безопасный перенос готовой сессии.

Можно выполнить вход на своём компьютере с этой же сборкой и зависимостями.
Укажи отдельную папку данных, три MANAGER_* переменные и выполни ту же команду.
После её завершения перенеси ТОЛЬКО `manager.session` защищённым способом
в `/app/data/smm/manager.session` остановленного серверного бота. Не запускай
два клиента с копиями одной сессии одновременно. Не публикуй файл сессии,
API hash, код и пароль в GitHub, Telegram-чатах или скриншотах.

Запусти бот → Менеджер → Подключение аккаунта → Проверить подключение.
После подтверждения создай/открой кампанию и нажми Старт. Пока ты этого не
сделаешь, черновик не начнёт рассылку. Существующие SMM credentials.json,
host.json, smm.sqlite и выбранная gpt-5.6-sol остаются на месте.

## Макет и дальнейшее развитие

Открой manager_preview.html в браузере на компьютере: можно переключать
Менеджер/СММ, смотреть карточку кампании, менять демонстрационный текст,
список групп и состояние Старт/Стоп. Это макет: он не связан с настоящим ботом.

Следующие полезные расширения менеджера: рабочие часы и дни недели, отправка
поста с фото/альбомом, статусы переговоров и напоминания о договорённостях.
Для СММ: календарь недели, шаблоны оформления по каналу, статистика одобрений
и подключение отдельного генератора изображений. Эти расширения пока не
реализованы; текущая сборка сохраняет существующий СММ и автопоиск одежды.

Справка: https://telegram.org/faq_spam,
https://core.telegram.org/method/channels.getChannelRecommendations,
https://docs.telethon.dev/en/stable/concepts/errors.html.
Локальные тесты используют подставные ответы; реальный аккаунт и Bothost
для новой рассылки в этой сессии не подключались. Сообщений не отправляли.
