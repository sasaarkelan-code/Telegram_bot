# Студия 2.4.1 · СММ + Менеджер

Полная самостоятельная веб-панель и Telegram-бот в одном Python-процессе. База, выбранная модель, авторизация, лимиты, каналы и очередь общие. Интерфейс рассчитан в первую очередь на телефон.

Начни с **INSTALL_BOTHOST_RU.md** — это инструкция для твоего текущего хостинга. Для отдельного Ubuntu VPS — **INSTALL_VPS_RU.md**. Пользование сайтом и установка на телефон — **MOBILE_AND_LOGIN_RU.md**.

## Аварийная защита 2.4.1

Перед каждой отправкой проверяются текст, редакторское одобрение автоматического поста, повторы и частота публикаций. Третья попытка в один канал за 10 минут, превышение дневного предела по расписанию, повтор или явный испорченный текст вызывают общую аварийную остановку. Три неудачные редакторские подборки подряд также останавливают систему. Публикации и рассылки прекращаются, очередь уходит в черновики, владельцу отправляется приоритетное сообщение Telegram независимо от обычных переключателей. После перезапуска остановка сохраняется; восстановление только вручную. Подробности: **UPDATE_2_4_1_RU.md**.

## Два раздела

| СММ | Менеджер |
|---|---|
| Лента всех постов и фильтры | Рассылки с кнопками Старт / Стоп |
| Предложения, черновики, текст и фото | Быстрая замена общего поста |
| Календарь и время каждого поста | Группы, паузы и период повторения |
| Источники, фильтры, расписание подбора | Поиск до 10 каналов для сотрудничества |
| Найти два поста сейчас / остановить поиск | Избранные партнёры и ссылки |
| Расход, лимиты и сохранённая модель | Подключение аккаунта и журнал отправок |

Команда и настройки общие. Меню разделов не смешивается. На телефоне доступны два верхних переключателя и нижняя навигация внутри выбранного раздела.

## Вход

1. Только владелец или принятый совладелец отправляет своему Telegram-боту `/web`.
2. Бот пишет логин и случайный одноразовый код на 5 минут.
3. На сайте вводятся Telegram username (с @ или без) и код. Если username нет, подходит числовой Telegram ID, который укажет бот.
4. Код работает один раз. Сессия сайта — 24 часа. Отзыв доступа сразу закрывает сессии совладельца.

Сервер хранит хеши кодов и сессий; токен бота и вход ChatGPT не передаются браузеру. Подключай сайт по HTTPS. Для локального теста по HTTP нужен отдельный `SMM_WEB_COOKIE_SECURE=0`; на публичном сервере оставь `1`.

## Публикации

Автоматический цикл: источники → отбор ИИ → редакторская проверка в том же запросе → очередь → публикация. Для подключённых включённых каналов новый режим включается при обновлении. Поиск начинается за 40 минут до времени выпуска; точная минута запуска больше не требуется. Новости по умолчанию выходят в 09:00, 15:00 и 21:00 МСК, до двух постов с паузой 5 минут. В настройках каждого канала можно выбрать от одного до двух постов, время и паузу.

ИИ отмечает решение и причину проверки; публикация дополнительно требует источников, неизменённого после проверки текста и готовности материала. Не прошедшие проверку посты остаются в ленте с объяснением. Для одежды обязательны реальные проверенные товары и картинка. Новости и кино могут выходить текстом, если включён соответствующий переключатель. Вручную можно одобрить пост одной кнопкой для ближайшего свободного времени или назначить свою дату. Правка текста/фото снимает публикацию с очереди.

Ошибка ИИ или исчерпание бюджета подбора не останавливают уже готовую очередь. Неопределённая отправка блокирует только свой канал до ручной сверки, остальные продолжают работу. Штатный перезапуск больше не устанавливает общую паузу; явная пользовательская пауза сохраняется. Старые черновики не публикуются массово. Подробнее: **UPDATE_2_4_RU.md**.

При обновлении модель не меняется. Если у тебя выбран `gpt-5.6-sol`, он остаётся. Счётчики не обнуляются. Новые лимиты сами по себе не увеличивают лимит подписки ChatGPT.

## Рассылки

По умолчанию: 2 минуты между группами и 30 минут между началами кругов. Если группы не помещаются в круг, период удлиняется. Текст можно менять на ходу — новая версия применяется к ещё не начатым отправкам. Стоп прекращает последующие отправки; уже начатая может завершиться.

Отправка и поиск партнёров требуют отдельно подключённого Telegram-аккаунта (MANAGER_API_ID, MANAGER_API_HASH и сессия). Пока аккаунта нет, можно готовить кампании и менять настройки. Партнёрам приложение автоматически не пишет, не подписывается и не предлагает сотрудничество. Ограничения Telegram учитываются остановкой; интервал не гарантирует отсутствие блокировки.

## Данные и обновления

Постоянная папка на Bothost: `/app/data/smm`. Приложение создаёт резервную копию перед первым запуском веб-обновления в `/app/data/backups`. Для дополнительной копии: `python backup_data.py`.

Не заменяй папку данных содержимым архива. В релизе нет пользовательской базы, токенов, сессий и тестовых демонстрационных записей. Сохраняются существующий владелец, совладельцы, каналы, авторизация и очередь. После обновления проверь паузу и нажми «Продолжить», если перед установкой остановил СММ вручную. Резервные копии содержат входы — храни их приватно, вне GitHub.

Python 3.11+, Flask + Waitress, SQLite, Telethon для менеджера. Сборка Node.js не нужна. Старт — `python main.py`. Настройка — через ENV. Один токен Telegram не запускай одновременно на компьютере и сервере.

Проверки: `python -m unittest discover -s tests -t . -q`.

## Лента и источники

Вход сразу в ленту, без обзора и большого баннера. Основное меню: Лента, Календарь, Каналы, Ещё. Поиск, расход, команда и настройки доступны из «Ещё». Менеджер использует отдельное меню.

Для финансов, футбола, ИИ и кино предусмотрены наборы RSS. Обновление один раз дополняет источники распознанных каналов, сохраняя свои ссылки и фильтры. Для канала с нестандартным названием выбери набор вручную: Каналы → Настроить → Добавить набор источников → Сохранить настройки. До 30 лент на канал; все указанные ленты участвуют в чтении. В карточке канала видно, когда проверялся каждый источник и произошла ли ошибка.

Для «Собрано» новые запросы не записываются в журнал токенов и не блокируются внутренними денежными/токенными бюджетами. Старый журнал не удаляется. Расход на стороне поставщика ИИ остаётся. Сохраняются пауза, срок выполнения, ограничение повторов, проверка источников товаров и проверка готовности перед публикацией. Другие каналы сохраняют строгий бюджет; переключатель в «Ещё → Расход ИИ» включает режим предупреждений.

Подробнее об обновлении и установке: **UPDATE_2_2_RU.md**.

## Telegram и уведомления

Управление остаётся на сайте. Telegram-бот выдаёт ключ входа через /web и принимает приглашения совладельцев через /join. В версии 2.4 владельцу снова приходят короткие сводки о найденных и опубликованных материалах, ошибках и неполных подборках. Старые административные кнопки не выполняют действий.

В «Ещё → Настройки → Уведомления Telegram» есть общий переключатель и три категории событий. Старый журнал не рассылается заново. Ошибка доставки уведомления не останавливает публикации. На сайте доступен колокольчик и история; статус прочтения отдельный для каждого участника. Для публикаций BOT_TOKEN и права администратора канала нужны по-прежнему.
