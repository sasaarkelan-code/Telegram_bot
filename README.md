# SMM Manager: Python worker for Deployka

Это сборка для загрузки в «Свой код / ZIP». Исходники находятся в корне ZIP.
Выбирай Python / Telegram bot / worker, а не Next.js или Node.js.

## ENV

| Имя | Значение |
| --- | --- |
| SMM_DATA_DIR | `/data/smm` |
| BOT_TOKEN | Токен своего управляющего бота из BotFather |
| OWNER_ID | Свой числовой Telegram ID, не username и не номер телефона |
| PYTHONUNBUFFERED | `1` — необязательно |

Секреты вводятся только в ENV проекта. Не помещай их в ZIP или скриншоты.
На первом запуске OWNER_ID обязателен. Неизвестные пользователи не получают доступ.
Если владелец уже сохранён, другой OWNER_ID не заменит его автоматически.

## Запуск

- Python 3.11+ (рекомендуется 3.12).
- Установка зависимостей: `pip install -r requirements.txt`.
- Команда запуска: `python -u main.py`.
- Procfile: `worker: python -u main.py`.
- Один экземпляр процесса. HTTP-порт для этого polling-бота не используется.

Сначала исправь исходники: замени загруженный ZIP этим архивом. После сканирования
должна определиться Python-сборка. Не применяй рекомендацию Next.js / Node Pro.
Проверь, что у выбранного тарифа есть постоянный /data и фоновый процесс.

Останови экземпляр этого же бота на компьютере перед запуском здесь.
Открой Logs, затем отправь своему боту /start или /menu.
Новая база содержит шесть начальных профилей на паузе. Доходить до публикаций
следует только после проверки подключения каналов и ИИ.

## Существующие данные и ИИ

Перенос кода не переносит настройки с компьютера. База smm.sqlite, config.json,
host.json и credentials.json хранятся отдельно от исходников. Для существующей
базы нужен согласованный backup и защищённый перенос в /data/smm. Не загружай
личную базу и файлы входа как публичные исходники проекта.

Этот архив запускает меню без интерактивного SETUP.bat. Он не выполняет вход
ChatGPT в браузере и не подменяет его API-ключом. Настройка подписки остаётся
отдельным шагом. Доступ к терминалу или защищённой загрузке файлов /data
на конкретном тарифе Deployka нужно подтвердить перед переносом входа.
Без перенесённого подключения и выбранной модели подготовка ИИ недоступна.
Не переноси ID установки другого устройства как ID новой серверной установки.

Документация платформы:
https://deployka.dev/en/deploy-from-chatgpt
https://deployka.dev/ru/blog/telegram-bot-sqlite-persistent-data

Сборка проверена локальными тестами. Реальный деплой и вход на Deployka
не проверены. Менеджер сохраняет кампании; рассылка с аккаунта пока не реализована.

Мобильная загрузка: main.py также поддерживает случай, когда файлы папки smm оказались в корне. Лучше сохранять исходную структуру папок.
