# Вход и управление с телефона

## Как защищён вход

Панель закрыта. Знание ссылки и username не даёт доступа.

В Telegram-боте отправь `/web`. Команда работает только в личном чате для основного владельца и совладельцев. Бот берёт настоящий username из сообщения Telegram и привязывает код к числовому Telegram ID. На сайте введи этот username и код. Если username отсутствует, используй Telegram ID, указанный ботом.

Код случайный, 5 минут, одно использование. Предыдущий неиспользованный код этого аккаунта заменяется новым. Если поменял username — запроси новый код. Код даёт полный доступ; не отправляй его другим. На сервере сохраняется хеш, а не сам код. После входа браузер получает HttpOnly-cookie; JavaScript не читает её. Дополнительно используются CSRF-проверка и ограничение попыток. Сессия действует 24 часа. «Выйти» закрывает текущую сессию; отзыв прав совладельца закрывает все его сессии.

Это вход через нашего бота, без отдельного пароля и без настройки Telegram Login Widget. В коде нет общего пароля и скрытой тестовой авторизации.

## Установить на главный экран

Открой именно HTTPS-адрес панели.

**Android:** Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран». Также в самой студии: Настройки → «Установить приложение». Если браузер не показывает системную установку, панель выдаст подсказку.

**iPhone:** Safari → «Поделиться» → «На экран Домой» → «Добавить». Если есть параметр открытия как веб-приложения — включи его. Для установленного приложения может потребоваться собственный первый вход.

Это готовая основа PWA: manifest, иконки, открытие отдельным окном и служебный worker. Она не требует публикации в App Store / Google Play. Нативный APK/IPA в архив не входит. Данные аккаунта и ответы API не сохраняются в офлайн-кеше. Для управления нужна сеть. Если закрыть приложение на телефоне, сервер продолжает подбор и запланированные отправки.

## Где что находится

Сверху два раздела — **СММ** и **Менеджер**. Их меню разделены. Внизу экрана — четыре кнопки выбранного раздела. Дополнительные функции доступны через кнопку меню слева вверху. Любое окно можно закрыть крестиком; системная кнопка «Назад» возвращает на предыдущий экран.

**СММ:** Лента → Календарь → Каналы → Ещё. В «Ещё» находятся поиск, расход, уведомления, команда и настройки.

**Менеджер:** Рассылки → Партнёры → Аккаунт → Журнал.

**Общее:** Команда, Настройки, выход из аккаунта.

## Пост: от поиска до публикации

1. Каналы → Настроить → подключи канал, проверь тему и источники.
2. Включи канал, «Автоматически искать по расписанию» и «ИИ сам одобряет и публикует».
3. Укажи время публикаций по Москве, число постов за выпуск (1–2) и паузу между ними.
4. Поиск начнётся за 40 минут до выпуска. ИИ отберёт и проверит материалы; прошедшие проверку попадут в календарь автоматически.
5. Для немедленного подбора нажми «Найти … сейчас». Одобренный ИИ результат займёт ближайшее свободное время в расписании.
6. Для вмешательства: Лента → пост → изменить, отклонить, снять с очереди или перенести время. Ручная кнопка «Одобрить и поставить в очередь» также назначает ближайшее свободное время.
7. Правка текста/фото снимает пост с очереди. Повторное одобрение после правки выполняешь ты. Автопилот не перезаписывает отредактированные черновики.

Поиск останавливается после заданного количества подходящих материалов либо после ограниченной попытки. При нехватке остаётся один или ни одного с объяснением. Для одежды нужны проверенные товары и картинка; непроверенные подборки удерживаются. «Пауза» останавливает новые запросы и отправки; уже начатая операция может завершиться. Неопределённую отправку нужно сверить с каналом и отметить результат — автоматического повтора нет. Подробнее: UPDATE_2_4_RU.md.

## Рассылки

Менеджер → Новая рассылка → название, общий пост, группы. Сначала создаётся черновик. После подключения Telegram-аккаунта доступен «Старт». По умолчанию: первая группа сейчас, следующая через 2 минуты, затем ещё через 2 минуты. Новый круг — не раньше 30 минут от начала предыдущего; длинный список удлиняет круг.

«Изменить» → новый общий текст применяется к будущим отправкам. Список групп и интервалы меняются отдельно; их изменение останавливает кампанию до повторного запуска. «Стоп» отменяет следующие отправки. Журнал содержит результат каждой попытки и ручную проверку неопределённых отправок.

Поиск партнёров показывает ссылки максимум на 10 новых публичных каналов за запуск. Добавляй избранные и открывай ссылки самостоятельно. Сообщений им приложение не пишет.

## Совладельцы

Команда → Пригласить → Telegram ID участника. Передай ему выданную `/join ...`. Участник сам отправляет команду нашему боту и получает полный доступ. После этого он использует `/web` для своего кода. Действует одно незавершённое приглашение на 30 минут; новое заменяет предыдущее.

Основной владелец сохраняется в базе и не удаляется из панели. Любой совладелец имеет полный доступ, включая управление другими совладельцами. Выдавай эти права только доверенным людям.

Официальные справки по установке:
- Apple: https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios
- Chrome: https://developer.chrome.com/docs/lighthouse/pwa/installable-manifest

## Предложения и внешний вид

Материалы сгруппированы по каналам. Есть фильтр канала, поиск по тексту и фильтры «Вся лента», «Запланированы», «Нужно внимание», «Черновики». В карточке — краткая суть, канал, статус и дата. По нажатию открывается безопасный предпросмотр в стиле Telegram: заголовок, картинка, текст, ссылки и цены берутся из того же представления, которое отправляет бот. Вид шрифтов/переносов в настоящем Telegram зависит от устройства.

Стеклянные поверхности, мягкие цветовые градиенты и анимации переходов адаптированы под телефон. При включённом в системе уменьшении движения анимации отключаются. Проверка новых данных не перерисовывает неизменившиеся карточки каждые 15 секунд.

## Уведомления и Telegram

История событий доступна через колокольчик либо «Ещё → Уведомления» обоим разделам. «Прочитать всё» отмечает события только для твоего входа.

В версии 2.4 владельцу дублируются в Telegram результаты, ошибки и неполные подборки. Настройки: «Ещё → Настройки → Уведомления Telegram». Можно отключить всё либо отдельные категории. Повторной рассылки старого журнала нет. Управление остаётся на сайте; в Telegram — ключ входа /web и принятие приглашения /join, старые кнопки управления отключены.
